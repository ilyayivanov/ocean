# Настройка DNS-резолвинга в сети MikroTik через WireGuard

Эта инструкция адаптирована под вашу конкретную топологию сети для организации доступа к статическим DNS-записям дачного роутера при удаленном подключении по WireGuard.

## Параметры вашей сети
* **Квартирный роутер (Сервер с белым IP):**
  * WireGuard IP: `192.168.100.1/24`
  * Локальная сеть (LAN): `192.168.88.0/24`
* **Дачный роутер (Пир со статическими DNS):**
  * WireGuard IP: `192.168.100.101/24`
  * Локальная сеть (LAN): `192.168.89.0/24`
* **Удаленный клиент (Телефон / Ноутбук):**
  * WireGuard IP: `192.168.100.3/32`

---

## 1. Настройка на дачном MikroTik (`192.168.100.101`)
Дачный роутер должен разрешать прием DNS-запросов из туннеля и знать обратный маршрут до вашего телефона (`192.168.100.3`).

### Через графический интерфейс (WinBox / WebFig):
1. **Разрешите удаленные запросы DNS:** В меню **IP → DNS** поставьте галочку **Allow Remote Requests**. Убедитесь, что в поле **Servers** прописаны внешние DNS (например, `1.1.1.1`, `8.8.8.8`), чтобы на телефоне работал интернет.
2. **Откройте порт в Firewall:** В разделе **IP → Firewall → Filter Rules** разрешите входящий трафик (`chain=input`) на порт `53` (UDP и TCP) с интерфейса `wg-sphere-pdlsn`. Перетащите это правило **выше** запрещающего правила `drop all`.
3. **Проверьте Allowed Address:** В разделе **WireGuard → Peers** откройте пир квартирного роутера и убедитесь, что в поле **Allowed Address** указана вся подсеть туннеля `192.168.100.0/24` (а не только `192.168.100.1/32`).

### Готовые команды для терминала (New Terminal):
```routeros
/ip dns set allow-remote-requests=yes servers=1.1.1.1,8.8.8.8

/ip firewall filter
add chain=input action=accept protocol=udp dst-port=53 in-interface=wg-sphere-pdlsn place-before=1 comment="Allow DNS over WG (UDP)"
add chain=input action=accept protocol=tcp dst-port=53 in-interface=wg-sphere-pdlsn place-before=1 comment="Allow DNS over WG (TCP)"

# Убедитесь, что у пира в сторону квартиры разрешена вся подсеть 192.168.100.0/24
/interface wireguard peers set [find allowed-address~"192.168.100.1"] allowed-address=192.168.100.0/24,192.168.88.0/24
```

---

## 2. Настройка на квартирном MikroTik (`192.168.100.1`)
Квартирный роутер выступает хабом и должен маршрутизировать пакеты между клиентом (`192.168.100.3`) и дачей (`192.168.100.101`).

### Через графический интерфейс (WinBox / WebFig):
1. **Настройте Allowed Address для пиров (WireGuard → Peers):**
   * Для пира **Дача**: `192.168.100.101/32, 192.168.89.0/24`
   * Для пира **Телефон**: `192.168.100.3/32`
2. **Разрешите транзитный трафик (IP → Firewall → Filter Rules):** В цепочке `forward` должно быть разрешено прохождение пакетов с интерфейса `wg-sphere-krsznm` на интерфейс `wg-sphere-krsznm` (Hairpin/Client-to-Client трафик внутри туннеля).

### Готовые команды для терминала (New Terminal):
```routeros
# Разрешаем обмен трафиком между клиентами внутри интерфейса WireGuard
/ip firewall filter
add chain=forward action=accept in-interface=wg-sphere-krsznm out-interface=wg-sphere-krsznm place-before=1 comment="Allow WG client-to-client routing"
```

---

## 3. Настройка клиента WireGuard (Телефон / Ноутбук)
В конфигурации вашего мобильного устройства укажите дачный роутер в качестве DNS-сервера:

```ini
[Interface]
PrivateKey = <ВАШ_ПРИВАТНЫЙ_КЛЮЧ_КЛИЕНТА>
Address = 192.168.100.3/24
DNS = 192.168.100.101

[Peer]
PublicKey = <ПУБЛИЧНЫЙ_КЛЮЧ_КВАРТИРНОГО_РОУТЕРА>
Endpoint = <БЕЛЫЙ_IP_КВАРТИРЫ>:<ПОРТ_WG>
# Для полного туннеля (весь трафик через квартиру):
AllowedIPs = 0.0.0.0/0
# ИЛИ для раздельного туннелирования (только доступ к локальным сетям квартиры и дачи):
# AllowedIPs = 192.168.100.0/24, 192.168.88.0/24, 192.168.89.0/24
PersistentKeepalive = 25
```

## Альтернатива: условная пересылка DNS (если на даче нестабильный интернет)
Если связь с дачей периодически обрывается, при настройке выше на телефоне перестанут открываться обычные сайты. Чтобы избежать этого, используйте квартирный роутер как основной DNS, а на дачу пересылайте запросы только для дачной доменной зоны (например, `.dacha`).

*(Работает в **RouterOS v7**)*:

1. В конфиге **телефона** укажите DNS квартирного роутера:
   ```ini
   DNS = 192.168.100.1
   ```
2. На **квартирном роутере** (`192.168.100.1`) включите `Allow Remote Requests`, откройте порт `53` для `wg-sphere-krsznm` и добавьте правило пересылки в терминале:
   ```routeros
   /ip dns set allow-remote-requests=yes
   /ip dns static add regexp=".*\\.home.arpa" type=FWD forward-to=192.168.100.101 comment="Forward .home.arpa DNS requests to pdlsn-ac3"
   ```
   *(Если у вас используются имена без доменной зоны, например просто `nas` или `camera`, добавьте отдельные FWD-записи для каждого имени).*
